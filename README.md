# OinKquest 🐷
Um aplicativo de gestão financeira gamificado focado na facilidade e microanimações. O projeto utiliza elementos narrativos de um RPG de texto para combater a falta de metas no cuidado com o dinheiro, substituindo gráficos complexos por uma jornada com missões, HP e um mascote tradicional de porquinho.

🛠️ Tecnologia Utilizada

Front-end Mobile: React Native operando sobre o framework Expo.
